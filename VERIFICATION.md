independently cross-checked, and what a reader should do if a result does not
reproduce.

## 2. Determinism

All computations are deterministic except one: the initial guess handed to the
SLSQP optimiser in Experiment B, which is drawn from
`np.random.default_rng(0)`. The seed is fixed in `hyperbench/exp_b_viq.py`, so
repeated runs on the same environment produce identical output.

The optimiser converges to the same optimum from other seeds as well — that is
the point of the experiment, since the optimum is known analytically and the
solver is being validated against it — but the exact digits at the 10⁻⁶ level
depend on the starting point, and hence on the seed.

**Floating-point caveat.** Byte-identical JSON output is expected only on the
environment of record. A different BLAS build, CPU, or library version can
change the final bits of some values. That changes the SHA-256 digests without
indicating any error. The authoritative check is therefore the tolerance-based
test suite, not the checksums.

or, for a fully isolated check:


**Figures.** Figure 1 is generated by `figures/make_architecture_figure.py`

## 6. Errors found during development

Both were found by the automated checks rather than by inspection, and both are
recorded because they failed *silently*.

**Optimiser returned values below a proven bound.** An early version of
Experiment B produced |I_V| smaller than b₀/2 — impossible under Proposition 1.
The proof was correct; the constraint specification was not. A truncated domain
let the optimiser leave b non-zero at the outer edge, discarding the −b₀
boundary term, so it was correctly solving the wrong problem. Asymptotic
matching to flat space is now enforced explicitly. The analytic bound functioned
as a test oracle; without it the wrong result would have looked publishable.

**Truncated semi-infinite integral.** The VIQ quadrature originally used a
uniform grid to a finite radius. For shape functions decaying as r^−α, the
integrand's tail falls as r^−(1+α), so truncation discards a contribution of
order r_max^−α — still about 1% at r_max = 10⁴b₀ for α = 0.5. The published
Table 3 relative errors were wrong as a result. Adaptive quadrature on [b₀, ∞)
fixed it, improving agreement from ~10⁻³ to ~10⁻¹⁵. This was caught by
`test_b_proposition_1_lower_bound`.

**Two SymPy pitfalls** are documented in `README.md` and in the manuscript
(§5.3): assumption mismatches that make `subs` silently no-op, and `sqrt(x*x)`
reintroducing unresolvable `Abs()` nodes in frame projections.

All 40 references in the manuscript were checked against primary sources —
publisher records, arXiv listings, or reference lists of peer-reviewed articles.
DOIs appear only where directly confirmed; where a DOI could not be verified,
the journal citation and a verified arXiv identifier are given instead. Three
errors were corrected during this pass:

  different paper (the "Part I" preprint, not the *Journal of Computational

- Maldacena, Milekhin and Popov is no longer a preprint; it appeared in
  *Classical and Quantum Gravity* 40, 155016 (2023).
- Baumgarte and Shapiro's title begins "On the numerical integration…", which
  had been truncated.

## 8. If a result does not reproduce

1. Run `make test`. Tolerance-based assertions are authoritative; checksum
   differences alone are not an error.
2. If tests fail, run `make docker` to rule out environment drift.
3. If they still fail, the discrepancy is real. Please open an issue including
   your platform, `pip freeze` output, and the failing assertion.
